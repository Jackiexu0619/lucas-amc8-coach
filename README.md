# Lucas AMC8 Coach v0.6.1 — 防重复调度版

本版在300题结构化题库基础上加入“原题冷却 + 同技能迁移复测”。

## 每日3题的原题冷却

系统不再因为某题做错，就第二天又把同一道原题拿出来。

规则：

- 答错 / 不会 / 未做：原题冷却 7 天
- 猜对：原题冷却 7 天
- 执行错误：原题冷却 14 天
- 做对但明显偏慢：原题冷却 14 天
- 独立正确：原题冷却 30 天

冷却只限制“同一道原题”。

如果某个技能需要第二天复测，系统会优先从同技能的其他题里挑迁移题，所以仍然可以快速补弱项。

## 周末25题防重复

生成新周末卷时：

1. 最近4套周末模拟卷里出现过的原题，禁止再次进入；
2. 最近7天周中训练做过的原题，也禁止进入本周周末卷；
3. 同一套卷中仍然不重复题目；
4. 同一核心方法仍然最多2题；
5. 原来的难度骨架仍保留。

如果题库在这些限制下真的无法组成25题，系统会明确提示，不会偷偷放宽规则。

## 复测节奏小修正

修复了“第一次独立做对被当成第二次正确”的计数问题。

现在独立正确原题的复测间隔按：
- 第1次独立正确：7天
- 第2次：14天
- 后续稳定：30天

技能层面仍会根据错因更快复测，但复测时优先换题，不直接刷原题。
