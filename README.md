# Lucas AMC8 Coach v0.6.2 — 双引擎选题版

本版把“周中练什么”和“周末怎么组卷”彻底拆成两套引擎，避免用同一个综合分数既做专项训练又组正式模拟卷。

## 1. Daily Adaptive Engine：每日3题

固定三槽位：

1. **近期弱项迁移**：根据最近21天的错误/猜测、技能掌握度和目标难度选题；优先避开昨天同一“领域+技能+核心方法”的同模型题。
2. **到期复测**：按技能复测日期选题；同一道原题仍受7/14/30天冷却，但允许使用同技能其他迁移题。
3. **广度/陌生题型**：优先最近7天出现较少的领域、方法和未做过技能；尽量与前两题换领域、换方法、换题族。

### 难度自适应

- 知识/公式不会、方法没想到：下一次该技能目标难度可下降1级搭桥。
- 执行错误、时间问题：不自动降难度，优先换题验证。
- 猜对：不升级难度。
- 同技能连续2次独立正确：目标难度提高1级，最高4级。
- 无历史记录时：通常从难度2开始；明显低掌握技能可从难度1起步。

### 复测节奏

技能层独立正确按迁移题累计，而不是只统计同一道原题：

- 第1次独立正确：7天后复测
- 第2次独立正确：14天后复测
- 后续稳定：30天后复测
- 知识/方法错误：1天后复测
- 执行错误：2天后复测

原题冷却继续保留：答错/不会/未做/猜对7天，执行错误14天，独立正确30天。

## 2. Exam Assembly Engine：周末25题

周末卷先满足正式AMC8结构，再加入有限个性化。

### 难度骨架

界面按六段理解：Q1–5 / Q6–10 / Q11–15 / Q16–20 / Q21–23 / Q24–25。
底层难度映射保持：

- Q1–8：难度1
- Q9–16：难度2
- Q17–21：难度3
- Q22–25：难度4

### 题型配额

每套25题从以下真实考试风格范围中选择一个可行配置：

- 应用/运算/比例/行程：6–7题
- 几何/坐标/空间：5–6题
- 组合/概率：4题
- 数论：3–4题
- 规律/逻辑：2–3题
- 数据统计：1–2题

同时按难度段优先接近以下结构：早段应用题更多，中段逐步增加几何/数论/组合，后4题更偏组合、数论、几何等高阶结构。

### 硬约束

- 最近4套周末卷出现过的原题不重复；
- 最近7天周中训练做过的原题不进入周末卷；
- 同一核心方法最多2题；
- 同一“领域+技能+核心方法”题族最多1题，防止只换数字的兄弟题扎堆；
- 不允许连续3题同一领域；
- Q21–25至少覆盖3个不同领域；
- 个性化弱项权重只作用于7/25个位置（28%），其余位置优先保证正式卷结构和广度；
- 如果全部条件无法同时满足，明确报错，不静默放宽规则。

## 3. 题库与真题

- 结构化训练题：300题，83个技能标签，81种核心方法。
- 真题索引：2019、2020、2022–2026，共175题。
- 本地真题PDF：2019、2020、2022、2023、2024。
- 2025、2026保留在线原卷入口。

## 4. 使用方式

工作流不变：系统选题 → 家长打印 → Lucas纸上完成 → 家长录入答案、用时和错因。

周末第一次生成25题后会锁定卷号；打印卷、网页预览和答案录入都绑定同一卷号。
