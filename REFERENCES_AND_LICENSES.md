# References and licenses

## Authentic AMC8 structured data
v0.6.3 loads structured AMC8 problem data from:
- `iuruoy-shao/training-problems`
- `problem-classification/amc_8_problems_with_sol.json`
- `problem-classification/outputs_file_8.txt`

The application uses 2015–2018 as its active historical training pool and keeps 2019–2026 separate for full-exam/recent-exam workflows.

The upstream repository and the underlying competition problem content may have separate licensing/copyright terms. Public accessibility is not the same thing as public-domain status. This project records source attribution and does not claim ownership of AMC problem statements.

## Legacy generated bank
The v0.6.0 300-question generated bank is retained only for local historical-record compatibility and is not automatically scheduled in v0.6.3.
